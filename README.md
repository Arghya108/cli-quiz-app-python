# cli-quiz-app-python
<img width="1422" height="788" alt="image" src="https://github.com/user-attachments/assets/0eace9df-4d21-434d-8dc8-57b312e3399e" />


A terminal-based quiz application built with Python's standard library.
Supports difficulty levels (Easy, Medium, Hard), per-question countdown
timer, randomized question order, and a final score report with grade.
Questions are loaded from a JSON file — making it easy to extend with
your own content. No external dependencies required.
